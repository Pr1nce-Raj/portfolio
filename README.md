## 🎯 Overview

This is not a standard portfolio—it's a gamified, tactical web experience. Designed with a strict "Dark Tactical / Modern Gamer" UI, this portfolio treats the user as an operative exploring a classified dossier. Visitors earn XP, unlock achievements, and level up their clearance tiers by interacting with different components of the site.

## ✨ Features

- **Gamification Engine:** Powered by Zustand and synced to `localStorage`. Earn XP by scrolling, reading sections, and interacting with elements. Rank up from *Explorer* to *Global Elite*.
- **Achievement System:** 10+ hidden and visible achievements complete with tactical Toast notifications (`sonner`).
- **Web Audio API Synthesizer:** Zero MP3s. All interactive sounds (tactical hover blips, metallic impact clicks, water droplets) are mathematically synthesized in real-time using the browser's native audio engine.
- **Night Vision Mode:** A custom theme toggle that drops a pitch-black shroud over the UI, featuring a dynamic green monochrome radial-gradient "torch" tied to your cursor physics.
- **Hidden Terminal Emulator:** Find the hidden `<terminal>` easter egg to open a fully functional, sanitized React command-line interface with custom commands (try `help`, `projects`, `sudo rm -rf /`).
- **Tactical Mobile Responsiveness:** Flawless zero-latency touch physics on smartphones, replacing standard menus with quick-nav tactile boxes and robust mathematical smooth-scrolling to eliminate layout thrashing.

## 🛠️ Tech Stack

- **Framework:** React + Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS + custom tactical animations
- **Animation:** Framer Motion
- **State Management:** Zustand (with persist middleware)
- **Icons:** Lucide React

## 🚀 Getting Started

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Pr1nce-Raj/portfolio.git
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the tactical development server:**
   ```bash
   npm run dev
   ```
4. **Build for production:**
   ```bash
   npm run build
   ```
